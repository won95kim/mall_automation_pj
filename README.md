# 🛍️ 쇼핑몰 자동화 테스트

본 프로젝트는 Selenium을 활용하여 실제 쇼핑몰 웹사이트의 일부 기능을 자동화한 개인 프로젝트입니다.  
테스트는 **비상업적이며 학습 목적**으로만 수행되었습니다.  
  
---
  
## 🔧 프로젝트 개요

Python과 Selenium을 기반으로, 실제 쇼핑몰 사이트의 핵심 사용자 기능을 자동화 테스트하였습니다.  
본 프로젝트에서는 다음 두 가지 기능을 중점적으로 테스트했습니다.  
  
- ✅ **최근 본 상품 기능**: 사용자가 상품을 클릭했을 때, 해당 상품이 '최근 본 상품' 전용 페이지에 정상적으로 기록되는지 확인  
- ✅ **상품 상세 페이지 기능**:   
  - 상품 제목, 이미지, 가격 등의 정보가 정상적으로 출력되는지 확인  
  - 옵션 드롭다운 선택 시 정상적으로 옵션이 노출되고 선택 가능한지 확인  
  - 구매 관련 버튼(장바구니, 바로구매 등)이 정상적으로 동작하는지 확인  
  - 하단 고정형 바로구매 버튼 클릭 시에도 정상적으로 동작하는지 확인  
  - 상세정보, 리뷰, Q&A 등 탭 클릭 시 해당 영역으로 정상 이동하는지 확인  
  - '장바구니', '바로구매' 버튼 클릭 시 각각 장바구니 페이지, 비회원구매 페이지로 이동하는지까지만 확인 (결제 단계는 테스트 범위 제외)

## 🚀 테스트 자동화 환경

본 프로젝트는 로컬 테스트 외에도 Jenkins와 Allure를 활용해 테스트 자동화를 구성하였습니다.  
  
- Jenkins 프리스타일 프로젝트로 구성하여, 정기적 또는 수동 트리거 방식으로 테스트 실행  
- Pytest 실행 시 `--alluredir` 옵션을 사용해 Allure 리포트용 데이터 생성  
- Allure Report를 통해 테스트 결과를 시각적으로 확인하고 이슈를 빠르게 파악 가능  
- 테스트 환경은 `requirements.txt`로 의존성을 관리하여 일관된 실행 환경 유지

## 🚨 유의사항

- 본 테스트는 실제 서비스를 무단으로 침해하거나 영향을 주지 않기 위해,  
  **로그인 없이 접근 가능한 영역만 테스트**하며 최소한의 트래픽으로 수행하였습니다.  
- 테스트 대상 사이트는 **국내 의류 쇼핑몰**이며, URL 및 상호명은 비공개 처리되었습니다.
